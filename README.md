# 🏠 Stayora - Hostel Finder

Stayora is a web-based hostel finder application designed to help
students easily discover and compare hostels near their college.

Instead of searching for hostel information from different sources,
Stayora provides important hostel details in one place.

## 🚀 Features

- 🔍 Search hostels by name and location
- 👩 Girls / 👨 Boys hostel filtering
- 💰 Filter hostels by maximum rent
- 🍽️ Food availability filter
- 🛏️ View total and available beds
- 📍 View hostel distance
- ⭐ View hostel ratings
- 📞 Contact hostel using phone number
- 👤 User registration
- 🛠️ Admin panel for hostel management
- 🗄️ Database-driven hostel information
- 📱 Responsive user interface
